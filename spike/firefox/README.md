# WhatsappRS Firefox denemesi

Bu bağımsız deneme, Mozilla Firefox üzerinde WhatsApp Web akıcılığını ve aramaları sınar. Mevcut WhatsappRS uygulamasını değiştirmez. Ayrı bir profil kullanır ve WhatsApp'a yeniden bağlanmak gerekir.

ZIP'i tamamen bir klasöre çıkartıp `WhatsappRS-Firefox-Deneme.exe` dosyasını açın. İndirme paketinde Mozilla Firefox bulunur. Pencereyi normal kapatın. Bu prototipte sistem tepsisi, okunmamış rozeti, otomatik güncelleme ve uygulamaya özel diğer özellikler henüz yoktur. Çağrı desteği ve uzun süreli performans henüz doğrulanmamıştır. Tarayıcı arayüzünü gizleyen CSS Firefox sürümleri arasında değişebilir. Bu prototip otomatik Firefox güncellemesini doğrulamaz; uzun süreli kullanım için tasarlanmamıştır.
